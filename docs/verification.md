## 覆盖范围

- 普通按钮不误提交表单；附件打开与删除分别可用键盘触达。
- 分段选择的循环、禁用选项、单一 tab stop 和 RTL 方向。
- 模拟输入法事件、Shift+Enter、异步发送去重、发送中新增草稿和失败重试。
- 复制成功/失败反馈、实际剪贴板写入与换行归一化。
- 流式滚动跟随、回看历史和跳转最新。
- 三类页面 × 桌面/360px 窄屏 × 浅深色：布局、焦点、axe 检查、控制台和截图。
- 可选面板的键盘关闭与焦点恢复、参数导入导出、存储不可用、损坏预设、减少动效优先级。
- 1360px/360px × 浅深色 × 三种强调色的调节台检查。
- 配置文件真实应用后重新构建，验证页面保留设置且不加载面板、不访问浏览器预设。

## 如何复验

按 README 安装依赖和 Chromium，执行全部检查命令。Playwright 原始报告会写到本机 `test-results/results.json`，失败时保留截图和 trace。原始报告含本机绝对路径，故不作为源代码提交；公开的[用例结果摘要](test-summary.json)仅保留用例名、状态及数量。

`node scripts/capture.mjs` 可重拍 README 的四张展示截图。它使用独立本机端口 4176，不连接第三方数据接口。

尚未验证 Firefox、Safari、真实手机、系统输入法实机行为或屏幕阅读器。自动化检查与合成输入法事件不能替代这些验证；美观和使用满意度也不由测试数量直接证明。
