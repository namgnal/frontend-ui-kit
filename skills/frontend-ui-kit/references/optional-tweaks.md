# 可选参数调节

用户平时仍用一句话让 Codex 优化页面，直接完成设计、实现与检查。不要因为有此模块就要求用户开面板、选参数、导入文件或走额外流程。用户明确想亲手比较或要求面板时，才接入此模块；语言调整也能直接由 Codex 修改配置或项目源码。

## 适用范围

面板用于已具备基本方向的页面微调。支持强调色、正文字号、内容间距、圆角、微反馈时长与标题，以及原版对比、恢复、显式本机保存、JSON 导入导出。它不会自动重排页面、修复业务流程、评价设计好坏或替代产品调研。

资源在 `assets/tweaks/`。React 控件与状态 hook 是可选开发资源；数据契约 `model.mjs` 和专用配置文件可独立使用。不依赖第三方状态库、浏览器扩展、模型服务、代码执行或 DOM 源码匹配。

## 默认隔离与接入

1. 普通产品入口保持既有流程，不导入 `DesignTweaksPanel`、`useDesignTweaks` 或 `controls.css`。面板放在独立开发入口，或项目已有的明确开发开关后，避免正式产品出现调节入口。
2. 用项目已有 tokens 和业务状态接入：`previewVariables(values, dark)` 只生成白名单 CSS 变量，`title` 作为普通文本绑定到指定标题，不能当作 HTML。`preview.css` 只示范本包组件的正文与间距映射；目标产品要明确绑定自己的布局，不宣称任意页面自动可调。
3. `useDesignTweaks(config)` 只在启用面板的开发入口挂载，使用固定 projectId 区分产品/页面。在组件外校验源配置。更换配置基线时重新挂载工作台，避免旧会话修改混入新基线；不要每次拖滑块都重新挂载预览。
4. 面板关闭只隐藏控件，保留当前预览和产品内正在编辑的状态；“对比原版”暂看基线，“恢复原版”恢复配置并清除该项目的本机记录。其他项目的存储保持不动。
5. 应用选定结果后，正式入口只读取已确认的配置/设计变量，不导入面板、hook 或浏览器预设。可按项目情况直接转为原有 CSS tokens。必须实际构建与预览，不能仅写出 JSON 就宣称界面已更新。

可复用结构：

```tsx
// 仅位于开发工作台；示意 Product 的实际 props 由目标项目决定。
const controls = useDesignTweaks(config);
const variables = previewVariables(controls.preview, isDark);
// 将 variables 绑定到产品局部容器，把 title 作为文本传给产品。
// 预览与面板是兄弟节点；关闭面板不卸载产品。
```

## 数据契约

`design.config.json` 是专用源配置，包含 `kind/version/projectId/revision/values`。复制模板后给项目/页面设置唯一 ID。`values` 中：

| 字段 | 支持值 | 沿用原版 |
|---|---|---|
| accent | inherit / jade / ink / plum，示例强调色含深浅主题 | inherit |
| fontSize | 14–20px，步长 1 | null |
| spacing | 8–28px，步长 2 | null |
| radius | 控件 0–24px，步长 2；示例面板圆角为控件 + 8 | null |
| motion | 微反馈 0–400ms，步长 10 | null |
| title | 1–80 字符单行文本 | null |

上述范围是当前配方的边界，不是所有产品的设计标准。沿用值不写入覆盖变量，不强制替换品牌。扩大范围或增加选项时，同步更新契约、控件、接入和相关验证。用户系统的 reduced-motion 设置优先于面板中的动效值。

导出的参数含 projectId、完整基线 revision/values 和新的 values；导入前一次性校验所有字段，不部分应用。拒绝未知字段、不支持版本、异常范围和超过 64KB 的文件。保存到本机只属于当前浏览器与开发入口，不能称为已经修改源码。

## Codex 应用到源码

由 Codex 完成以下文件工作，用户无需手动跑命令。辅助脚本需要 Node.js 18+；本包实测 Node 24.12.0。

```text
node <skill>/scripts/apply-tweaks.mjs --config <project>/design.config.json --patch <exported>.tweaks.json --check
node <skill>/scripts/apply-tweaks.mjs --config <project>/design.config.json --patch <exported>.tweaks.json
```

仅对已明确接入的专用 JSON 配置使用。脚本对比项目 ID、基线版本和完整基线值；冲突时停止，不用强行修改版本绕过。检查当前差异，依据用户选定方向重新生成匹配最新基线的参数，再应用。它不会扫描、正则修改或并行覆盖 JSX/CSS。

应用时完整写入一份新配置，版本 +1，并保留原文件备份。脚本使用同目录临时文件、协作锁和写入前复查；它不承诺对不遵守锁的任意外部写入器提供数据库式事务。若文件正在被其他工具编辑，先协调或停止该写入。

## 验证

- 普通入口不渲染/加载面板，也不读写该模块浏览器预设；既有输入、键盘、复制、滚动、主题和窄屏回归通过。
- 逐项更改后真实预览，原版对比和恢复有效，调节/关闭不丢失产品草稿。
- 保存刷新、导出导入往返、坏文件与存储不可用均有清楚反馈；不同项目与旧基线不互相覆盖。
- 应用导出配置、构建正式入口后，界面保留结果但没有面板和本机预设依赖。
- 有效颜色与尺寸组合仍需按目标产品检查对比度、窄屏和减少动态效果，不把本包示例的测试当作目标产品已验收。
